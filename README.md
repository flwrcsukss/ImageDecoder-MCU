# ImageDecoder-MCU BETA
Pixel-by-pixel image decoder for MCU-driven displays.

Приложение попиксельно декодирует изображение на строки, на основе следующих настроек: начало отрисовки картинки по X/Y; шаг, с которым будет браться пиксель (функция сжатия); формат цвета (пока доступен только RGB, позже планируется RGBA, HEX, 16-бит); строка-константа, на основе которого будут строиться строки кода.
